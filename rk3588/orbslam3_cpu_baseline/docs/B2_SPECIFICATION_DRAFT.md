# B2 设计候选规格与验证口径

2026-10-05：用户批准本矩阵用于硬件选型，**不是定型 FPGA 规格**。参数集中在 configs/b2/design_candidates.json；B3 前可调整并重新验证。早期 panorama/ Demo 的参数、点对表、黄金模型不带入。

## 数据与边界

- MH01：752×480，不缩放；基准 1000 特征 / 8 层。
- Tello：只用飞行18:49:29、20:06:48；960×720，不缩放，1000/8，C2 provisional YAML。结果标注 **“借用内参，未本机标定”**，只报告相对 native 的变化，不报告绝对精度或真实尺度。
- 实现选择：**PS/CPU 软件模拟**，独立工具生成 B1 格式后 inject。跟踪、匹配旋转直方图、建图和优化不改；不修改 HLS/RTL。
- ORB_DESIGN_CANDIDATES 仅独立生成器启用。已验收 SLAM 主程序/库不重编，构建前后核对 SHA256。工作树与二进制来源提交分别记录。
- 未修改的 C1 源码快照在另一命名空间编译成独立参考，保留来源和哈希；V0 抽检全字段/描述子逐字节一致，避免同一修改版自比。

## 不变条件

单项变体以外保持：8层、scaleFactor=1.2、INTER_LINEAR、FAST20/7回退、原版分数/3×3NMS、四叉树、原版半径15圆形窗口IC角和umax、未模糊图计算FAST/IC、描述子前7×7 sigma=2模糊、标准bit_pattern_31_。

正常N=1000、初始化N=5000。预算沿用原版浮点公式/cvRound：第一层N(1−f)/(1−f^L)，逐层乘f，最后层残余，f=1/scaleFactor。P2正常667/333，初始化3333/1667。原版四叉树可能略超预算，不自行截断。

EDGE_THRESHOLD=19；四叉树/网格有效区域原点为19−3=16，宽高为层图减32。FAST自身另保留半径3边界。G用相同有效区域和约35像素FAST单元候选池，不改候选生成。FAST probe也用原版单元/NMS，报告单元池候选，不是另一个全图FAST实现。

## 编号

| 编号 | 设计候选 | 变化 |
|---|---|---|
| native | 原版CPU | 直接提取；B3重跑新五次基准 |
| V0 | 原版dump/inject | 注入链路对照 |
| P1 | 1层 | 全部预算原图层 |
| P2 | 2层 | scaleFactor=2，第1层2×2平均 |
| F | 固定FAST | 只用20，取消降到7回退 |
| G | 网格 | 替代四叉树 |
| A8 | 8档方向 | 描述子及输出角均用最近45°中心 |
| A32 | 32档方向 | 同A8，档宽11.25° |
| B | 去模糊 | 只取消描述子前高斯 |
| MIN | 最省资源组合 | P1+F+G+A8+B |

P2的8位平均需披露舍入：当前mean_rounding=0，四像素整数和除4向下截断；值1为加2后除4、半入。B3前可按负责人意见修改，此处不称硬件定型。

G：s=floor(sqrt(有效面积/预算))，行列数为有效长宽整除s，余数合并末行/列；每格最高FAST分数1点，同分选y/x光栅在前者；超预算全局分数降序/光栅同分截断，不足不回填。两档分别重算格子，记录候选、选中、空格、缺额；当前配置s≥1。

A8/A32：k=floor((θ+180/N)/(360/N)) mod N，描述子旋转及输出angle用k·360/N；旋转坐标仍为原版cvRound。两者对应旧提示词**V2b**；旧V2a只改描述子角、输出连续角，本轮没有V2a。

## FPGA输出草案

BRIEF已固定：所有变体必须用标准bit_pattern_31_、原版比特顺序；Demo自定义点对不适用于SLAM。保留B1小端版本化文件格式和整数纳秒时间戳。

| 字段 | PL/PS职责草案 | 精度/待确认 |
|---|---|---|
| 时间戳、图尺寸、版本、档位 | PS封装，PL回显frame_id | 纳秒整数，避免浮点秒往返 |
| 层号、层整数x/y | PL必须输出，PS乘原版float32尺度回第0层 | 坐标精度变化需另消融 |
| FAST分数 | PL必须输出整数 | 原版分数/NMS，PS可完成总预算截断 |
| 角度/档位 | PL输出连续角或候选档位 | 连续float32，量化由PS精确恢复中心；负责人确认候选 |
| size、尺度/sigma² | PS从YAML/层号推导 | size按原版31×尺度整数化；生成/注入元数据一致 |
| 描述子 | PL必须输出32字节 | 标准256对、bit顺序、cvRound |
| 正常/初始化档 | PS寄存器配置，文件头标role | 1000/5000切换、资源上限待负责人确认 |

## B2验证

1. 独立Python检查量化边界、网格余数/同分/截断/空格、2×2平均、预算。
2. 每段前两帧，9个inject候选各检查两档，共27组/108包；V0与未修改原版逐字节比对。
3. 固定每段**前600帧**做一次SLAM冒烟，共30次。全帧检查头/坐标/层分布/分数/size/角度；第0、100、200…帧保存内存快照并进行参考描述子检查。前缀只验证初始化/流程，不能替代完整序列稳定性结论。
4. 汉明比较使用候选的**相同层图像、相同整数关键点**，重新算原版连续IC+模糊+BRIEF。P2层像素不同，组件距离0不等于完整前端等价；选点影响交给SLAM评估。
5. 两段Tello全帧统计FAST10/15/20/25候选/G空格；两档用基准8层公式的**第0层预算**。只报告，不改F=20。
6. SLAM条件同B1：A76、CPU/DMC performance、实时节奏、无Viewer、降频暂停、恢复governor。初始化失败记录，不补跑挑结果。
7. 读文件/解码和Total−完整特征槽的剩余耗时分开报告。模拟器CPU提取时间只用于排程，不能当FPGA性能。
