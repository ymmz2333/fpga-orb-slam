正式标定脚本的--slam-fps为显式整数标称值（Tello默认30），容器fps在标定JSON中另行保留。
选择一段跟踪最稳定的数据，fx/fy 同时×0.9、×1.1 各3次，
与原候选比较初始化、OK比例、丢失次数及轨迹 Sim3 对齐差异。

## 当前实现与操作

- prepare_c.py：从C0字节副本解码灰度PNG；关联PC parser时刻，排除预录但保留损坏标记与时间空缺。
  第一张正式输入设为1,000,000,000 ns，以相对时间保存整数纳秒，不代表硬件曝光时间。
- validate_prepared.py / prepare_c_archive.py：帧覆盖、单调时间、尺寸与PNG SHA256验证，打包传输。
- 0010补丁：跟踪计时区间外增加MapStateStats.csv（地图编号、真实重定位成功标记），
  Shutdown后导出Diagnostics_maps.csv与各地图轨迹；FeatureTimeStats.csv原有内点记录保留。
  不修改ORB、匹配、优化或实时等待；正常模式仍native。
- batch_c.py：9段×3轮，按三次中最差OK比例最大、丢失最少选择相对最稳定片段，
  焦距±10%各3次；不挑选单次成功，不替换失败。不存在三次均初始化成功的片段时标记敏感性未完成。
- finish_c.py：用户回来后下载已结束批次，一行/次摘要、状态计时与Sim3轨迹一致性统计；
  轨迹误差单位是参考SLAM任意单位和归一化RMS，不能写成米或ATE。
- export_c_loss_images.py：无损复制丢失前后帧，再人工审阅原因；未确认首尾同位置前不声称闭合误差。

# 9×6为内角点数量；0.025仅为命令示例，实际参数必须来自实物棋盘格。
